# Password Strength Checker

A Python-based cybersecurity tool that checks the strength of a password using common password security requirements.

## Description

The Password Strength Checker evaluates a password based on factors such as:

- Password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

It then provides a strength assessment and helps users understand whether their password meets basic security standards.

## Features

- Checks password length
- Detects uppercase and lowercase letters
- Checks for numbers
- Checks for special characters
- Provides password strength feedback
- Simple command-line interface

## Technologies Used

- Python 3
- Regular Expressions (`re`)
